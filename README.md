# API Testing Project

A practice automation project I built while learning API testing.
It uses Rest Assured with Java to test a free public API (Fake Store API).

## Tools Used
- Java
- Rest Assured
- TestNG
- Maven
- Postman

## What This Project Does
Tests the main API operations on a demo e-commerce API:
- GET – fetch products and categories
- POST – create a new product
- PUT – update a product
- DELETE – remove a product

Each test checks the status code and the response data.
A Postman collection is also included for trying the API by hand.

## How to Run
1. Clone this repository
2. Open the folder in VS Code
3. In the terminal, run: `mvn clean test`
